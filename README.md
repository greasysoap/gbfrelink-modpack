# Installation Instructions for Bazzite
1. Create folder "ProfileOptimization" to look like /var/home/<username>/.local/share/Steam/steamapps/compatdata/881020/pfx/drive_c/users/steamuser/Application Data/Reloaded-Mod-Loader-II/ProfileOptimization/
2. Deploy ASI Loader (from Reloaded)
3. Add launch options: WINEDLLOVERRIDES="winmm=n,b" %command%
